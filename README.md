# NeuroAssist AI

A NeuroAssist AI propõe uma plataforma de tecnologia assistiva que transforma pequenos movimentos voluntários residuais — de pessoas com doenças neurodegenerativas como ALS/MND — em pedidos de ajuda estruturados, capturados por uma webcam comum e processados por visão computacional.
