## Objetivo

Implementar os 45 cenários hoje em `test.skip()` na suíte `acs-e2e`. É o maior débito
isolado da suíte E2E do frontend.

## Contexto

3 arquivos, 45 `test.skip()`, **zero** testes ativos:

```
apps/acs-e2e/src/tenant-onboarding.spec.ts
apps/acs-e2e/src/caregiver-roster.spec.ts
apps/acs-e2e/src/patient-linkage.spec.ts
```

Todos com o mesmo corpo stub gerado por `fe-nx-register-module.py` (D-487):

```ts
test.skip('...', async ({ page }) => {
  await page.goto('/acs');
  await expect(page).toHaveURL(/.*/);   // asserção vazia
});
```

O cabeçalho de cada arquivo registra `TODO[FE-ACS-P9]: implement with real selectors
after fe-implement`. Os componentes já existem (`feature-tenant-setup`,
`feature-caregiver-roster`, `feature-caregiver-editor`, `feature-patient-linkage`),
portanto os seletores reais são obtíveis.

## Checklist

- [ ] `tenant-onboarding.spec.ts` — 8 cenários (provisioning ativo, pendente, retry ok, retry pendente, sem permissão, cuidador primário, breadcrumb, composição PAC/EDGE)
- [ ] `caregiver-roster.spec.ts` — cenários restantes
- [ ] `patient-linkage.spec.ts` — cenários restantes
- [ ] Nenhum `test.skip()` remanescente
- [ ] Nenhuma asserção `toHaveURL(/.*/)` (asserção vazia) remanescente
- [ ] Verde no perfil `mock` **e** no perfil `integrated`
- [ ] `data-testid` adicionados aos componentes onde faltarem

## Atenção

Um `test.skip` com `expect(page).toHaveURL(/.*/)` passa contra qualquer coisa. Ao remover
o `.skip` sem trocar a asserção, o teste fica verde sem testar nada — pior que skipped,
porque some do radar. Toda remoção de `.skip` exige asserção real.
