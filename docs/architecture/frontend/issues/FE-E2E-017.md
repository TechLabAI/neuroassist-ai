## Objetivo

Automatizar a execução do perfil `integrated`, para que a integração FE↔BE seja verificada
continuamente e não apenas uma vez.

## Desenho

```
PR (a cada push)          →  perfil "mock"
                             nx affected:test + nx affected:lint + e2e mock
                             rápido, sem Docker, hermético

NIGHTLY / pré-release     →  perfil "integrated"
                             docker compose -f docker/docker-compose.dev.yml up -d
                             seed (FE-E2E-016)
                             nx serve -c integrated
                             APP_URL=... nx run-many --target=e2e --all
```

Espelha a camada de execução do plano BE (§5.1: contrato a cada PR, integração cross-service
nightly, E2E de fluxo pré-release).

## Pré-requisito de build

O compose monta os jars via volume — exige build prévio:

```bash
cd backend && ./gradlew bootJar -x test
docker compose -f docker/docker-compose.dev.yml up -d
```
