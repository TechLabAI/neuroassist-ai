# FE-E2E-001 — Transporte: proxy.conf.json + configuração Nx `integrated`

**Módulo:** FE E2E Integration
**Fase:** F0 — Habilitação de Transporte
**Prioridade:** P1 (bloqueante)
**Status:** OPEN
**Criado em:** 2026-08-20
**Plano:** [plan-FE-E2E.md](../plans/plan-FE-E2E.md)

---

## Objetivo

Permitir que o `neuroassist-ai-web` servido em `localhost:4200` alcance o GWY em
`localhost:18080`, e que exista uma configuração Nx dedicada (`integrated`) que ative os HTTP
adapters — sem quebrar o modo `mock` default.

## Contexto

- Não existe `proxy.conf.json` no repositório (`find . -name "proxy*.json"` → vazio).
- Não existem arquivos de `environment` (`find apps libs -name "environment*"` → vazio).
- O alvo `serve` em `apps/neuroassist-ai-web/project.json` só tem as configurações
  `development` e `production`, ambas apontando para o mesmo build com adapters mock.

### ⚠️ Revalidação 2026-08-20 — duas premissas mudaram

1. **A porta do GWY no host virou `18080`** (o container segue em 8080). Parametrizar, não
   hard-codear: já mudou uma vez.
2. **O GWY normalizou o roteamento para `/api/v1/<svc>/**`** nos 7 serviços. Se a decisão
   (a) da §0 do plano for adotada, o proxy passa a precisar de **2 prefixos**, não 9.

## Cenários de Validação

| ID | Cenário | Critério |
|---|---|---|
| TRN-01 | Proxy roteia para `http://localhost:${GWY_PORT:-18080}` | `curl :4200/api/v1/hist/history` chega ao GWY |
| TRN-02 | `nx serve neuroassist-ai-web -c integrated` sobe com HTTP adapters | request de rede real observável no DevTools |
| TRN-03 | Endpoint de **negócio** de cada serviço responde ≠ `404` via GWY | ver G8 no plano — 4 serviços reprovam hoje |
| TRN-04 | CORS/preflight resolvido (ou desnecessário via proxy same-origin) | `OPTIONS` não bloqueia |

## Prefixos que o proxy DEVE cobrir

**Hipótese (a) — normalização no GWY (recomendada):**

```
/api/v1/**   → GWY   (os 7 serviços, superfície uniforme)
/oauth2/**   → GWY   (token, refresh, jwks — permitAll no SecurityConfig)
```

**Hipótese (b) — GWY espelha os paths reais:** voltam os 9 prefixos originais
(`/api/v1/acs/**`, `/api/pac/v1/**`, `/api/v1/events/**`, `/api/v1/reports/**`,
`/api/v1/hist/**`, `/api/v1/edge/**`, `/panel/**`, `/gest-service/**`, `/oauth2/**`).

A fragilidade de (b) é justamente o argumento a favor de (a).

## Checklist

- [ ] Decisão (a)/(b) sobre G8 fechada com o backend — **bloqueante**
