# FE-E2E-006 — Flip para adapter: 'http' por módulo, atrás de configuração

**Prioridade:** P1 (bloqueante)

## Objetivo

Ativar os HTTP adapters no perfil `integrated` **sem** perder o perfil `mock`.

## Contexto

`apps/neuroassist-ai-web/src/app/app.config.ts` — os 7 módulos em mock:

```ts
provideGest({ adapter: 'mock' }),
provideEvnt({ adapter: 'mock' }),
providePac({ adapter: 'mock' }),
provideAcs({ adapter: 'mock' }),
provideEdge({ adapter: 'mock' }),
provideHist({ adapter: 'mock' }),
provideDash({ adapter: 'mock' }),
```

Cada `provide<Module>()` já implementa o switch — a mudança é de **configuração**, não de código
de módulo. O comentário no topo do arquivo já antecipa isso: *"Flip individual modules to 'http'
once their backend + GWY route is deployed and reachable"*.

## Requisito de projeto — não substituir, configurar

Hoje há **44 testes Playwright verdes** contra mocks (`edge-e2e` 18, `gest-e2e` 14, `pac-e2e` 12).
Trocar `'mock'` por `'http'` no arquivo os quebraria e destruiria a suíte hermética que roda
sem Docker em todo PR. O flip **tem** de ser por configuração.

Abordagem: um token de DI (`APP_ADAPTER_MODE`) resolvido pela configuração Nx `integrated`,
consumido por um único ponto em `app.config.ts`.

## Checklist

- [ ] Token `APP_ADAPTER_MODE: 'mock' | 'http'` definido
- [ ] `app.config.ts` deriva os 7 `provide<Module>({ adapter: mode })` do token
- [ ] Configuração `integrated` resolve `'http'`; default permanece `'mock'`
- [ ] Flip **verificável por módulo** (permite integrar HIST antes de DASH, p.ex.)
- [ ] `nx serve` (default) → mock; 44 testes continuam verdes
- [ ] `nx serve -c integrated` → http; requests reais no DevTools
- [ ] `nx run-many --target=test --all` PASS
- [ ] `nx run-many --target=lint --all` limpo

## Ordem sugerida de flip por módulo

Do menos ao mais acoplado, para isolar falhas:

```
HIST  →  ACS  →  PAC  →  EDGE  →  GEST  →  EVNT  →  DASH
```

DASH por último: é o único que depende de SSE real (FE-E2E-011).
