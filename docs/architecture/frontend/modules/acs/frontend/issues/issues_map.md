## 8. Gaps rastreados (para scaffold/backlog atenção)

1. **Coverage-eligibility contract (ADR-005 + contracts/backend-api-cross-link.md §5):** definição de
   "alarm-eligible" entre FE (CoverageFacade) + BE (ACS) + EVNT ainda não congelada. FE deriva como
   `active link ⋈ active caregiver`. Congelar com EVNT antes do go-live.

2. **JWT residual window on deactivate (BE §4.4):** token válido até TTL após desativação — gap conhecido,
   fora de escopo para o FE no MVP.

3. **Shared ui-feedback modal API:** se o modal service não suportar modais fail-closed, implementar inline
   (FE-ACS-027 contém a instrução).

4. **PacientesReadClient latência (INT-FE-ACS-005):** client-side join em listForPatient pode ser lento
   com muitos cuidadores. Gap registrado como TODO no JSDoc do cliente.
