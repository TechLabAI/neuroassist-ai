# SPEC-03 — View Models — ACS (Frontend)

> Module: **ACS** · Generated by `/fe-architect-specs neuroassist-ai ACS` · 2026-07-29
> Sources: FE 03 §2/§3, FE 05 §1/§4, ADR-005 (coverage invariant), BE `api-contract.md` §3/§4/§5. VMs are
> `record`-like TS interfaces held in `data-access` facades as signals; components read `asReadonly()` views
> only. Coverage is a **computed** signal, never a stored mutable flag (FE 04 §6, ADR-005).

## 1. Roster view models

```ts
// One row of the caregiver roster (CaregiverRosterComponent)
interface CuidadorRowVM {
  readonly id: string;
  readonly nome: string;
  readonly login: string;
  readonly papel: 'cuidadora' | 'coordenador_clinica';
  readonly status: 'active' | 'inactive';                // BE soft-deactivate (api-contract §4.4)
  readonly linkedPacienteIds: readonly string[];         // active links (api-contract §5)
  readonly coverage: 'coberto' | 'sem-cobertura';        // DERIVED per linked paciente (never stored)
  readonly isLastCovering: boolean;                       // DERIVED: deactivate would drop a paciente to zero (ADR-005)
}

interface RosterKpiVM {
  readonly totalAtivos: number;                           // count status === 'active'
  readonly coordenadores: number;                          // count papel === 'coordenador_clinica'
  readonly pacientesSemCobertura: number;                  // count patients with zero active covering caregiver
}

type RosterLoadState = 'idle' | 'loading' | 'loaded' | 'error';
```

**UI events exposed by the roster VM:** `loadRoster`, `invite`, `edit(id)`, `deactivate(id)`,
`openLinkage(pacienteId)`, `retryLoad`.

## 2. Caregiver editor view models

```ts
// Editable caregiver fields (mirrors POST /caregivers body; senha write-only)
interface CuidadorFormVM {
  nome: string;                                           // required, trimmed non-empty
  login: string;                                          // required, trimmed non-empty; unique per empresa (BE 409)
  papel: 'cuidadora' | 'coordenador_clinica';
  senha: string;                                          // required on create only; never bound from a loaded caregiver
}

// BE status mirrored into UI editor state (api-contract §4 + local editing states)
type EditorState = 'idle' | 'editing' | 'saving' | 'saved' | 'deactivating' | 'error';

interface CaregiverEditorVM {
  readonly state: EditorState;
  readonly draft: CuidadorFormVM;
  readonly status: 'active' | 'inactive' | null;          // null = brand-new unsaved
  readonly isLastCovering: boolean;                       // DERIVED: blocks deactivate (ADR-005)
  readonly canSave: boolean;                              // derived: form valid (nome, login, papel, senha-on-create)
  readonly canDeactivate: boolean;                        // derived: status === 'active' && !isLastCovering
  readonly saveError: AppError | null;
}
```

**UI events exposed by the editor VM:** `startNew`, `startEdit(id)`, `patchDraft(partial)`, `save`,
`deactivate`, `cancel`, `retrySave`.

## 3. Patient linkage view models

```ts
// One active caregiver↔patient link row (PatientLinkageComponent)
interface VinculoRowVM {
  readonly linkId: string;
  readonly cuidadorId: string;
  readonly cuidadorNome: string;
  readonly papel: 'cuidadora' | 'coordenador_clinica';
  readonly caregiverStatus: 'active' | 'inactive';        // an inactive linked caregiver does NOT count as coverage (ADR-005)
  readonly isLastCovering: boolean;                       // DERIVED: unlink would drop paciente to zero → blocked
}

// Derived per-patient coverage (CoverageFacade — linkage ⋈ caregiver.active, FE 05 §1)
interface PatientCoverageVM {
  readonly pacienteId: string;
  readonly pacienteNome: string;
  readonly covering: number;                              // count of active alarm-eligible caregivers
  readonly state: 'coberto' | 'sem-cobertura';           // covering > 0 ? coberto : sem-cobertura (danger)
}

type LinkageMutateState = 'idle' | 'linking' | 'unlinking' | 'error';
```

**UI events exposed by the linkage VM:** `load(pacienteId)`, `link(cuidadorId)`, `unlink(cuidadorId)`,
`retryLoad`.

## Criterios de aceite (EARS)

> Clauses are one clause each and dot-free so the coverage gate extracts them whole; each shares domain nouns
> with a `Scenario:` title in `e2e/`.

- WHILE the roster load is in flight, THE SYSTEM SHALL show a loading roster state rather than stale rows.
- IF the roster load fails, THEN THE SYSTEM SHALL show an error roster state with a retry rather than an empty
  roster.
- WHILE a paciente has zero active covering caregiver, THE SYSTEM SHALL mark that paciente sem cobertura and
  keep it visible rather than hidden.
- THE SYSTEM SHALL derive the paciente coverage from the active links joined with each caregiver active status.
- WHILE a linked caregiver is inactive, THE SYSTEM SHALL exclude that caregiver from the paciente coverage
  count.
- WHILE the caregiver editor draft has a blank nome, THE SYSTEM SHALL keep the salvar cuidador action disabled.
- WHILE the caregiver editor draft has a blank login, THE SYSTEM SHALL keep the salvar cuidador action
  disabled.
- WHILE creating a new cuidador with a blank senha, THE SYSTEM SHALL keep the salvar cuidador action disabled.
- WHILE the caregiver is the last covering caregiver of a paciente, THE SYSTEM SHALL keep the desativar cuidador
  action disabled.
- THE SYSTEM SHALL render papel only as cuidadora or coordenador_clinica labels and never echo the senha of a
  loaded cuidador.
- WHILE the tenant provisioning is not yet confirmed, THE SYSTEM SHALL show a provisioning empresa state rather
  than an active empresa.
