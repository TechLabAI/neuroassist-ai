# Backend API Cross-Link — PAC (Frontend ↔ `pac-service`)

> Module: **PAC** · Generated by `/fe-architect-specs neuroassist-ai PAC` · 2026-07-28
> **Barrier (source of truth):** `docs/architecture/backend/services/pac-service/contracts/api-contract.md`
> (+ `data-model.md`, `event-contracts.md`). This file freezes which BE endpoints each FE surface consumes and
> where the FE aligns to (or previously diverged from) the barrier.

## 1. Base & headers (BE §1)

- Base path: `/api/pac/v1` (routed by GWY; discovered via REG). Media: `application/json`; errors
  `application/problem+json`.
- Mandatory request headers wired by FE interceptors:
  - `X-Empresa-Id` — from `@neuroassist/shared/empresa-context` (schema-per-empresa).
  - `Authorization: Bearer <JWT>` — from `@neuroassist/shared/auth-session`.
  - `X-Correlation-Id` — propagated by the shared HTTP base (BE echoes/generates).
  - `If-Match` — the FE sends the last-read `ETag` on every mutation (lifecycle/edit).
  - `Idempotency-Key` — the FE generates one per user-initiated `POST` create.

## 3. Reconciliation with the FE vision (divergence resolved)

| FE vision draft (doc 05 §2) | BE barrier | Resolution in specs |
|---|---|---|
| `remove(id): DELETE /comandos/{id}` | **No DELETE** — `:retire` (history-preserving, ADR-006) | FE "remover" ⇒ `PacComandoClient.retire`; catalog row action relabeled "Aposentar" |
| single `save` (create/update) | draft edit only while `drafted`; published ⇒ recalibrate | FE editor exposes `save` (draft) **and** `recalibrate` (published tuning) as distinct actions (SPEC-04) |
| implicit "active on save" | `estado` lifecycle + no device-ack contract yet | FE derives `syncState` from EDGE ack (ADR-005); never optimistic-active |

## 4. Error contract (BE §2 → FE)

All twelve `ProblemDetail` `type`s in BE §2 are mapped in `SPEC-07-error-handling.md` §1 to an FE surface
(inline/toast/banner/modal) and pt-BR message. Safety-critical mappings: `422 emergency-not-detectable` and
`503 eligibility-gate-unavailable` are **blocking / fail-closed** in the UI.

## 5. Known gap (carried from BE `event-contracts.md` §2.3)

An EDGE **device-ack** signal (which catalog version the edge has pulled) is **not yet contracted**. The FE
`syncState = synced` transition depends on it. Until an `EdgeDevicePort.confirmSync` contract exists, the FE
keeps commands at `pendente de sincronização` — an honest state, not an error (ADR-005). Tracked as a backlog
item (`pac.deferredEdgeSync` flag gates the surfacing). **Out of scope for these specs.**
