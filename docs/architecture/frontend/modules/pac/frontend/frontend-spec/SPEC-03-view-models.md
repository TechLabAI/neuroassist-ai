## 1. Catalog view models

```ts
// One row of the command catalog (CommandCatalogComponent)
interface ComandoRowVM {
  readonly id: string;
  readonly rotulo: string;                              // family label (never interpreted)
  readonly gestoDescricao: string;                      // "Sobrancelha" | "Sobrancelha + Piscar" (resolved names)
  readonly urgencia: 'emergencia' | 'rotina';
  readonly sensibilidade: 'baixa' | 'media' | 'alta';
  readonly estado: 'drafted' | 'validated' | 'published' | 'retired';  // BE lifecycle (api-contract §4)
  readonly calibracaoVersao: number;
  readonly tested: boolean;                             // a GEST live-test succeeded for this draft?
  readonly syncState: 'synced' | 'pending';             // ativo no dispositivo | pendente de sincronização
  readonly etag: string;                                // row version → If-Match on mutations
}

interface CatalogKpiVM {
  readonly total: number;
  readonly emergencias: number;                         // count urgencia === 'emergencia'
  readonly pendentesSync: number;                        // count syncState === 'pending'
}

type CatalogLoadState = 'idle' | 'loading' | 'loaded' | 'error';
```

**UI events exposed by the catalog VM:** `load`, `newCommand`, `editCommand(id)`, `recalibrate(id)`,
`retire(id)`, `retryLoad`.

## 2. Editor view models

```ts
// Editable identity + calibration fields (mirrors POST/PUT …/comandos body)
interface ComandoFormVM {
  rotulo: string;                                       // required, trimmed non-empty
  necessidade: string;                                  // required, trimmed non-empty
  urgencia: 'emergencia' | 'rotina';
  primitivoPrincipal: string;                           // TipoGesto id (GEST-owned)
  primitivoSecundario: string | null;                   // composite (optional, distinct from principal)
  sensibilidade: 'baixa' | 'media' | 'alta';
  tempoMinGestoMs: number;                              // > 0
  tempoMaxGestoMs: number;                              // > tempoMinGestoMs
}

// BE lifecycle mirrored into UI editor state (ADR-006 estados + local editing states)
type EditorState = 'idle' | 'editing' | 'saving' | 'saved' | 'validating' | 'publishing'
                 | 'recalibrating' | 'retiring' | 'error';

interface EditorVM {
  readonly state: EditorState;
  readonly draft: ComandoFormVM;
  readonly estado: 'drafted' | 'validated' | 'published' | 'retired' | null;  // null = brand-new unsaved
  readonly calibracaoVersao: number;
  readonly etag: string | null;                          // set once saved; If-Match source
  readonly syncState: 'synced' | 'pending';              // never 'synced' until EDGE device-ack (ADR-005)
  readonly canSave: boolean;                             // derived: form valid && identity editable
  readonly canValidate: boolean;                         // derived: estado === 'drafted'
  readonly canPublish: boolean;                          // derived: estado === 'validated'
  readonly canRecalibrate: boolean;                      // derived: estado === 'published'
  readonly canRetire: boolean;                           // derived: estado !== 'retired' && estado !== null
  readonly saveError: AppError | null;
}

interface TipoGestoVM {
  readonly id: string;
  readonly nome: string;
  readonly estado: 'supported' | 'pending-training' | string;  // detectability signal (advisory in UI)
}
```

**UI events exposed by the editor VM:** `startNew`, `startEdit(id)`, `patchDraft(partial)`,
`addTipoGesto(nome)`, `save`, `validate`, `publish`, `recalibrate`, `retire`, `cancel`, `retrySave`.

## Criterios de aceite (EARS)

> Clauses are one clause each and dot-free so the coverage gate extracts them whole; each shares domain nouns
> with a `Scenario:` title in `e2e/`.

- WHILE the catalog load is in flight, THE SYSTEM SHALL show a loading catalog state rather than stale rows.
- IF the catalog load fails, THEN THE SYSTEM SHALL show an error catalog state with a retry rather than an
  empty catalog.
- WHILE the loaded catalog contains no comando, THE SYSTEM SHALL show the empty state so the caregiver can add
  the first comando.
- THE SYSTEM SHALL derive the KPI counter of comandos pendentes de sincronização from the catalog rows.
- WHILE a comando saved edit is not acknowledged by the device, THE SYSTEM SHALL keep the comando pendente de
  sincronização rather than ativo no dispositivo.
- WHILE the editor draft has a blank rotulo, THE SYSTEM SHALL keep the salvar comando action disabled.
- WHILE the editor timing window minimo is not below the maximo, THE SYSTEM SHALL keep the salvar comando
  action disabled.
- WHILE the editor composite primitivo secundario equals the primitivo principal, THE SYSTEM SHALL keep the
  salvar comando action disabled.
- WHILE the editor comando is drafted, THE SYSTEM SHALL enable the validar action and keep the publicar action
  disabled.
- WHILE the editor comando is validated, THE SYSTEM SHALL enable the publicar action.
- WHILE the editor comando is published, THE SYSTEM SHALL enable the recalibrar action and keep the validar
  action disabled.
- WHILE the editor comando is retired, THE SYSTEM SHALL keep every lifecycle action disabled.
- THE SYSTEM SHALL render sensibilidade only as baixa media or alta labels, never as a raw threshold value.
