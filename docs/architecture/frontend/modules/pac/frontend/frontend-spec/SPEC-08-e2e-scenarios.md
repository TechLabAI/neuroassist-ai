## Scenario inventory

### command-catalog.feature
1. Open catalog with existing commands → rows render with rótulo, gesto, urgência, sensibilidade badges.
2. Open catalog with no command → empty state "Nenhum comando configurado" + "Adicionar primeiro".
3. KPI bar shows total, emergências, pendentes de sincronização counts.
4. A saved-but-unacknowledged command shows "pendente de sincronização" (never "ativo no dispositivo").
5. A device-acknowledged command shows "ativo no dispositivo".
6. Catalog load error → error card + "Tentar de novo" (no stale rows shown as fresh).
7. "Novo comando" hidden when caller lacks `pac.comando.write`.
8. Calibração nav item hidden when caller lacks `pac.comando.read`.

### command-editor.feature
1. New command draft opens empty in editing state.
2. Blank rótulo → "Salvar" disabled with inline hint.
3. tempoMin ≥ tempoMax → "Salvar" disabled with inline hint.
4. Composite with secundário == principal → "Salvar" disabled.
5. Save routine command → POST `/comandos` with Idempotency-Key → "pendente de sincronização".
6. Retried save reuses the same Idempotency-Key (no duplicate).
7. Validate a drafted command → `:validate` → estado validated.
8. Publish an emergency command whose gesture is not `supported` → 422 emergency-not-detectable → blocking
   modal, stays validated.
9. Publish an emergency command whose gesture is `supported` → `:publish` → estado published.
10. Publish with GEST gate unavailable (503) → retryable toast, not published.
11. Publish a routine command with a non-supported gesture → advisory banner, still published.
12. Recalibrate a published command → `:recalibrate` (If-Match) → calibracaoVersao +1, back to pendente sync.
13. Edit identity of a published command → blocked (invalid-lifecycle) → routed to recalibrate/retire.
14. Retire a command → `:retire` → terminal; further transitions rejected.
15. Save with stale ETag → 409 conflict-precondition → blocking modal, reload + reapply.
16. Inline "+ novo tipo" → delegates to GEST → returned id selected (naming ≠ detectability).
17. "Testar agora" mounts GEST GestureLiveTestComponent on the unsaved draft (test-before-save).
18. Save error (ProblemDetail) → toast, draft preserved, nothing marked saved.

### patient-register.feature
1. Register paciente in onboarding step 2 → POST `/pacientes` → step done, catalog step unlocked.
2. Blank nome → save disabled.
3. Unknown dispositivoEdgeId → 422 → inline error, paciente not created.
4. Unknown cuidadorResponsavelId → 422 → inline error.
5. ACS unreachable during save → 503 → retryable message, paciente not created.
6. Onboarding wizard owns the breadcrumb (PAC contributes none).
