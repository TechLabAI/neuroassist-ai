## 2. `MODULE_PERMISSION_MAP` (UI → BE scope)

UI permission keys map to BE OAuth2 scopes (`api-contract.md` §1.2). The UI enforces **defense-in-depth**;
the backend is authoritative.

| UI permission | BE scope | Justification |
|---|---|---|
| `pac.paciente.read` | `pac:patient:read` | render the paciente read-model / onboarding recap |
| `pac.paciente.write` | `pac:patient:write` | register/update paciente (onboarding step 2) |
| `pac.comando.read` | `pac:command:read` | show the command catalog |
| `pac.comando.write` | `pac:command:write` | author/edit a comando draft (editor) |
| `pac.comando.publish` | `pac:command:publish` | run lifecycle transitions (validate/publish/recalibrate/retire) |

```ts
export const MODULE_PERMISSION_MAP = {
  'pac.paciente.read':    'pac:patient:read',
  'pac.paciente.write':   'pac:patient:write',
  'pac.comando.read':     'pac:command:read',
  'pac.comando.write':    'pac:command:write',
  'pac.comando.publish':  'pac:command:publish',
} as const;
```

## 3. `MODULE_FEATURE_FLAGS`

| Flag | Default | Justification |
|---|---|---|
| `pac.inlineNewTipoGesto` | `on` | inline "+ novo tipo" affordance in the gesture picker (delegates to GEST); off hides it and forces pre-existing types only (FE 04 §7) |
| `pac.deferredEdgeSync` | `on` | surfaces the ADR-005 "pendente de sincronização / ativo no dispositivo" state; off collapses to a single saved state (used only if an EDGE device-ack contract is unavailable) |
| `pac.emergencyGateAdvisoryHint` | `on` | shows the advisory warning banner when a `rotina` command references a non-`supported` primitive (BE api-contract §4.6 advisory branch) |

```ts
export const MODULE_FEATURE_FLAGS = {
  'pac.inlineNewTipoGesto':        'on',
  'pac.deferredEdgeSync':          'on',
  'pac.emergencyGateAdvisoryHint': 'on',
} as const;
```

## Criterios de aceite (EARS)

> Clauses are one clause each and dot-free so the coverage gate extracts them whole; each shares domain nouns
> with a `Scenario:` title in `e2e/`.

- WHILE the caller lacks the comando write permission, THE SYSTEM SHALL hide the novo comando entry point.
- WHILE the caller lacks the comando publish permission, THE SYSTEM SHALL disable the validar publicar
  recalibrar and retirar lifecycle actions.
- WHILE the caller lacks the paciente write permission, THE SYSTEM SHALL disable the onboarding paciente save
  action.
- WHERE the inline novo tipo flag is off, THE SYSTEM SHALL hide the inline novo tipo de gesto affordance.
- WHERE the deferred edge sync flag is off, THE SYSTEM SHALL collapse the sync badge to a single saved state.
- WHILE the caller lacks the comando read permission, THE SYSTEM SHALL hide the Calibração nav item.
