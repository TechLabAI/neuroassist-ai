# SPEC-02 — Component Hierarchy — PAC (Frontend)

> Module: **PAC** · Generated by `/fe-architect-specs neuroassist-ai PAC` · 2026-07-28
> Sources: FE 02 §4, FE 04 §3, FE 05 §2. Smart components consume facades (signals); presentational
> components receive `@Input` and emit `@Output`. No `BehaviorSubject` in components (FE 05 §2).

> This SPEC is a component tree (prose) — no `## Criterios de aceite (EARS)` section (per command guide:
> EARS is not applied to component trees).

## 1. `feature-command-catalog` (`libs/pac/feature-command-catalog`)

```
CommandCatalogComponent  (smart)
│  reads signals: pacComandoFacade.catalog(), pacComandoFacade.loadState(), pacComandoFacade.kpis()
│  dispatches: load(), newCommand(), editCommand(id)
├── CatalogKpiBarComponent            (presentational)  @Input kpis: CatalogKpiVM
├── CatalogEmptyStateComponent        (presentational)  @Output addFirst  (shown WHEN catalog empty)
├── CatalogErrorCardComponent         (presentational)  @Input error: AppError  @Output retry
└── CommandRowComponent[]             (presentational, libs/pac/ui)
        @Input row: ComandoRowVM
        @Output edit  @Output recalibrate  @Output retire
        ├── UrgencyBadgeComponent        @Input urgencia
        ├── SensitivitySelectorComponent @Input sensibilidade (read-only display here)
        └── SyncStatusBadgeComponent     @Input syncState  ('synced' | 'pending')  (ADR-005)
```

Signals read by `CommandCatalogComponent`: `catalog` (`ComandoRowVM[]`), `loadState`
(`idle|loading|loaded|error`), `kpis` (`CatalogKpiVM`). The `syncState` per row is a **derived** signal
(catalog ⋈ EDGE device-ack, FE 05 §1); the row never invents `active`.

## 2. `feature-command-editor` (`libs/pac/feature-command-editor`)

```
CommandEditorComponent  (smart)
│  reads signals: pacComandoFacade.editorState(), pacComandoFacade.draft(),
│                 tiposGestoReadFacade.tipos(), pacComandoFacade.saveError()
│  dispatches: startNew()|startEdit(id), patchDraft(partial), addTipoGesto(nome),
│              save(), validate(), publish(), recalibrate(), retire(), cancel()
├── CommandFormComponent               (presentational)  @Input draft: ComandoFormVM  @Output change
│     ├── RotuloFieldComponent           @Input value  @Output change   (required, synchronous validator)
│     ├── UrgencySelectorComponent       @Input urgencia  @Output change
│     ├── GesturePickerComponent         @Input tipos, principal, secundario  @Output pick / addNew
│     │     └── (inline "+ novo tipo" → emits addNew(nome); delegated to GEST — FE 03 §3)
│     ├── SensitivitySelectorComponent   @Input sensibilidade  @Output change
│     └── TimingWindowComponent          @Input min,max  @Output change   (min<max synchronous validator)
├── CommandPreviewComponent            (presentational)  @Input draft  (human-language preview, no thresholds)
├── LifecycleActionBarComponent        (presentational)
│     @Input estado ('drafted'|'validated'|'published'|'retired')
│     @Output save @Output validate @Output publish @Output recalibrate @Output retire
│     (buttons enabled/disabled per estado — SPEC-03/SPEC-05)
├── SyncStatusBannerComponent          (presentational)  @Input syncState  (ADR-005 pendente de sincronização)
└── ⟨live-test slot⟩  ← GestureLiveTestComponent (GEST-owned) is composed HERE by the SHELL page,
                          NOT imported by PAC. PAC exposes an ng-content slot / the shell wraps both.
```

`CommandEditorComponent` declares it reads exactly: `editorState` (`EditorState`), `draft`
(`ComandoFormVM`), `tipos` (`TipoGestoVM[]`), `saveError` (`AppError | null`).

## 3. `feature-patient-register` (`libs/pac/feature-patient-register`)

```
PatientRegisterComponent  (smart)  — composed inside ACS onboarding wizard step 2
│  reads signals: pacPacienteFacade.patient(), pacPacienteFacade.saveState()
│  dispatches: savePatient(nome, dispositivoEdgeId?, cuidadorResponsavelIds?)
├── PatientFormComponent               (presentational)  @Input value  @Output change
│     ├── NomeFieldComponent             @Input value  @Output change  (required)
│     ├── DispositivoEdgePickerComponent @Input deviceRef  @Output change  (optional; EDGE ref by id)
│     └── CuidadorMultiSelectComponent   @Input caregivers  @Output change  (ACS refs by id)
└── PatientSaveStatusComponent         (presentational)  @Input saveState  @Output retry
```

`PatientRegisterComponent` reads: `patient` (`PacienteVM | null`), `saveState`
(`idle|saving|saved|error`). It contributes **no breadcrumb** (onboarding shell owns the wizard trail).

## 4. Shared / domain libs (no page components)

- `libs/pac/data-access` — clients + facades (SPEC-04); exposes signals only.
- `libs/pac/access` — `pacTenantPatientGuard`, `pacCommandWriteGuard`.
- `libs/pac/integration` — `PacShellIntegrationService` (SPEC-06).
- `libs/pac/navigation` — breadcrumb/menu state (SPEC-01 §1, FE 05 §6).
- `libs/pac/ui` — `CommandRowComponent`, `UrgencyBadgeComponent`, `SensitivitySelectorComponent`,
  `SyncStatusBadgeComponent`, `SyncStatusBannerComponent` (pure presentational, no facade access).
