## 1. Resumo do projeto

O módulo PAC é o **system of record** para Paciente e Catálogo de Comandos da plataforma NeuroAssist AI. No frontend, PAC implementa três features routed: `CommandCatalogComponent` (visão geral de todos os comandos do paciente com KPIs de sincronização), `CommandEditorComponent` (autoria draft-first de comandos com ciclo de vida completo) e `PatientRegisterComponent` (composto dentro do wizard ACS — não routed pelo PAC).

A característica central do FE PAC é o **honest-state de sincronização** (ADR-005): nenhum comando é marcado como "ativo no dispositivo" sem device-ack do EDGE — um contrato que ainda não existe no MVP e é coberto pelo stub `EdgeDeviceAckStubAdapter` (INT-FE-PAC-001), mantendo todos os comandos em `'pendente de sincronização'` até que o contrato EDGE seja implementado.

Adicionalmente, o **emergency gate** (ADR-005 BE / SPEC-07) é safety-critical: a publicação de um comando `urgencia=emergencia` é fail-closed na UI — 422 `emergency-not-detectable` resulta em modal bloqueante (não dismissível via ESC/click externo), garantindo que nenhum comando de emergência seja publicado para um gesto não detectável.

## 4. Riscos top-3

| # | Risco | Probabilidade | Impacto | Mitigação |
|---|---|---|---|---|
| R1 | **EDGE device-ack contract ausente** (ADR-005 gap): `syncState` nunca transita para `'synced'` no MVP. Banner "pendente de sincronização" permanece sempre visível. | Alta (confirmado no MVP) | Médio (UX degradada, não bloqueante) | `EdgeDeviceAckStubAdapter` (INT-FE-PAC-001) implementa honest-state explícito; flag `pac.deferredEdgeSync` controla visibilidade do badge. O gap é rastreado e aceito como limitation intencional do MVP. |
| R2 | **Emergency gate blocking modal** pode falhar se `@neuroassist/shared/ui-feedback` não suportar `blocking: true` (non-dismissible). | Média | Alto (safety-critical) | Validar `FeedbackService.showModal({ blocking: true })` antes de PAC-FE-021; se não existir, implementar o modal blocking como componente local em `libs/pac/ui` antes de ship. |
| R3 | **GEST TipoGesto endpoint** (`/api/gest/v1/tipos-gesto`) pode não estar disponível no MVP (gest-service em desenvolvimento). | Média | Baixo (editor funciona com lista vazia; requestNew disabled) | `TiposGestoReadFacade.load()` degrada silenciosamente para `tipos=[]`; editor ainda funciona sem o picker populado. Flag `pac.inlineNewTipoGesto=off` desabilita o affordance "+ novo tipo". |
