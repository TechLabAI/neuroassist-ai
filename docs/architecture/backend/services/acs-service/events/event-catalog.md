## Overview

`acs-service` **publishes no asynchronous events and consumes none** (broker disabled in MVP).
All inter-service interactions are synchronous REST. This catalog records the six **domain facts**
ACS records to HIST via synchronous REST, as per `contracts/event-contracts.md §1`.

---

## Domain Facts (synchronous REST to HIST — not async events)

| Fact | Emitted when | Target | Delivery |
|---|---|---|---|
| `TenantProvisionado` | Tenant transitions to `active` (SPEC-02) | HIST | Synchronous REST, best-effort |
| `CuidadorRegistrado` | Caregiver created (SPEC-01 §4.1) | HIST | Synchronous REST |
| `CuidadorDesativado` | Caregiver deactivated (SPEC-01 §4.4) | HIST | Synchronous REST |
| `CuidadorVinculadoAoPaciente` | Link created (SPEC-05 §4) — anchor event | HIST | Synchronous REST |
| `CuidadorDesvinculado` | Link revoked (SPEC-05 §4) | HIST | Synchronous REST |
| `AutenticacaoRealizada` | Login success (SPEC-03) | HIST | Best-effort, non-blocking |
| `AutenticacaoFalhou` | Login failure (SPEC-03) | HIST | Best-effort, non-blocking |

---

## Fact Payload Envelope

```json
{
  "fact": "<FactName>",
  "empresaId": "t_0f8a…",
  "actorId": "<uuid>",
  "correlationId": "<uuid>",
  "occurredAt": "2026-07-29T14:10:00Z",
  "payload": {}
}
```

No biometric, clinical, or credential data is ever included in any fact payload (LGPD hard rule).
