## 5. Test data strategy

- **Tenant:** use `empresa-abc` as the default test tenant in all scenarios. `empresa-xyz` is used as the foreign tenant.
- **Resource IDs:** fixed UUIDs in test data (e.g. `pac-001`, `cmd-emg`) resolved by Cucumber type registry to test UUIDs.
- **Port stubs:** GEST, ACS, EDGE, HIST are stubbed via WireMock (HTTP) in integration tests. Provide a `TestPortsConfig` Spring config that wires stubs to the port interfaces.
- **DB:** integration tests use an embedded PostgreSQL (Testcontainers) with the per-empresa schema pre-created.
