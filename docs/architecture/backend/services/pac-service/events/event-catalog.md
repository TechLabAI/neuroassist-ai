## Messaging status

There is **no async message broker** in the NeuroAssist AI MVP. PAC publishes **no asynchronous events**
and consumes none. All inter-service interactions are synchronous REST (GWY/REG).

Domain facts are recorded **synchronously** to HIST (`hist-service`) at the end of each successful
lifecycle transition — they replace async bus events. See `contracts/event-contracts.md §1` for the full
fact payload schema and resilience policy.

## Published events (async) — N/A

**None.** Reevaluation trigger: if the pilot grows to many patients/edges, the synchronous model is the
first candidate to move behind a broker (RabbitMQ) — a known future decision, not MVP scope.

---

## Consumed events (async) — N/A

**None.** PAC does not subscribe to any event stream.

---

## Port interface (`HistFactPort`)

```java
package com.neuroassist.pac.application.port;

public interface HistFactPort {
    void record(DomainFact fact);   // throws HistUnavailableException on failure
}
```

On failure: lifecycle transition stays committed; fact is enqueued to a local retry outbox and retried.
See `contracts/event-contracts.md §1` and `spec/backend/SPEC-09-messaging-architecture.md` for full
resilience policy.
