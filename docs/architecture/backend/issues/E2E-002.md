# E2E-002 — Auth Backbone: JWT ACS validado por todos os serviços

**Módulo:** E2E Cross-Service  
**Fase:** F2 — Auth Backbone  
**Prioridade:** P1 (bloqueante)  
**Status:** OPEN  
**Criado em:** 2026-08-20  
**Plano:** [plan-e2e-integration.md](../plans/plan-e2e-integration.md)

---

## Objetivo

Verificar que o JWT emitido por ACS (RS256, assinado com a chave persistida no banco) é aceito como token de autenticação válido por todos os 7 microserviços configurados como OAuth2 Resource Servers — e que tokens expirados ou inválidos são rejeitados uniformemente com `401`.

## Cenários de Validação

| ID | Cenário | Endpoint | Critério |
|---|---|---|---|
| AUTH-01 | Login com credenciais válidas | `POST /oauth2/token` | `200` + `accessToken` RS256 assinado |
| AUTH-02 | Login com credenciais inválidas | `POST /oauth2/token` | `401` sem enumerar qual campo falhou |
| AUTH-03 | Refresh token rotation | `POST /oauth2/token/refresh` | `200` + novo par com novo `jti` |
| AUTH-04 | JWT aceito em PAC | `GET /api/v1/pac/patients` com token ACS | `200` ou `403` por papel — nunca `401` |
| AUTH-05 | JWT aceito em HIST | `GET /api/v1/hist/history` com token ACS | `200` ou `403` — nunca `401` |
| AUTH-06 | JWT aceito em EDGE | `GET /api/v1/edge/devices` com token ACS | `200` ou `403` — nunca `401` |
| AUTH-07 | JWT aceito em EVNT | `GET /api/v1/evnt/events/active` com token ACS | `200` ou `403` |
| AUTH-08 | JWT aceito em GEST | `GET /api/v1/gest/detection-profiles/active` com token ACS | `200` ou `403` |
| AUTH-09 | JWT aceito em DASH | `GET /api/v1/dash/panel/...` com token ACS | `200` ou `403` |
| AUTH-10 | Token expirado rejeitado em todos | qualquer endpoint com JWT `exp` no passado | `401` em todos os 7 serviços |

## Pré-condições

- E2E-001 concluído (stack UP)
- Signing key persistida no banco de ACS (ACS P7 — ACS-026 DONE)

## Checklist

- [ ] AUTH-01: login retorna par de tokens RS256
- [ ] AUTH-02: credencial inválida retorna `401` sem user enumeration
- [ ] AUTH-03: refresh rotation gera novo `jti` (par substituído)
- [ ] AUTH-04..09: JWT ACS aceito em todos os 6 serviços restantes
- [ ] AUTH-10: JWT expirado rejeitado com `401` em todos os 7
