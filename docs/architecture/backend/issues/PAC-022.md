# PAC-022 -- Implementar GlobalExceptionHandler com RFC 7807 ProblemDetail para todos os tipos de erro (SPEC-01 §6)

**Done/Total:** 0/4 itens

## Contexto
`GlobalExceptionHandler` (`@RestControllerAdvice`) é responsável por mapear TODAS as exceções de
domínio e infraestrutura para RFC 7807 `ProblemDetail` (`application/problem+json`). A tabela de
mapeamentos é definida em SPEC-01 §6. O `correlationId` do MDC deve aparecer em toda resposta de
erro. O handler é o único lugar que conhece o mapeamento exception→HTTP status.

## Spec de referencia
- SPEC-01 §6 (error model — RFC 7807 ProblemDetail, todos os tipos)
- `contracts/api-contract.md` §2 (error types)
