# E2E-027 — Não existe CI: nenhum gate roda sem alguém digitar o comando

## Contexto

O repositório não tem pipeline de CI. Todo gate — `test`, `architectureCheck`, `integrationTest` —
depende de alguém rodar localmente e reportar. Duas consequências já observadas:

1. **61 dos 62 `application/port/out/*.java` ficaram fora do versionamento** e ninguém percebeu:
   `out/` no `.gitignore`, sem barra inicial, casa em qualquer profundidade. O Gradle compila o
   **diretório de trabalho**, não o índice do git — nenhum gate local podia detectar, e não havia
   CI para compilar o que estava no repositório.
2. `:test` não roda `integrationTest`, então um `*IT` quebrado convive com gate verde.

Sem CI, "os 7 módulos estão verdes" é uma afirmação sobre a última vez que alguém rodou, não sobre
o estado do repositório.

## Escopo

- Workflow que faz **clone limpo** (é o que teria pego o defeito do `.gitignore`) e roda
  `build` + `architectureCheck` nos 7 serviços
- `integrationTest` com Docker disponível no runner
- E2E-013 (suíte automatizada) plugada quando existir
- Gate obrigatório no PR para `dev`

## Critério de aceite

Abrir PR com um teste quebrado, ou com um arquivo que existe só no disco, e o PR ficar vermelho.
