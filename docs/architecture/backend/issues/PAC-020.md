**Status:** INTACT -- gerado 2026-07-28
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/4 itens

## Contexto
A read surface do catálogo (`GET .../catalogo-ativo`) é consumida por GEST para snapshot do
`DetectionProfile` (ADR-004). Expõe somente comandos `published` com seus tuning params atuais.
Suporta `If-None-Match` (ETag = `catalogoVersao`): se não mudou, retorna `304 Not Modified` sem body.
É a fonte de verdade de calibração — GEST nunca escreve nela, apenas lê (pull-based, SPEC-09/10).
