## Contexto
Criar as entidades JPA que mapeiam as tabelas definidas em `contracts/data-model.md`. O schema
routing (multi-tenant por empresa) é gerido pelo `TenantSchemaResolver` — as entidades em si
não carregam `tenant_id` como PK mas devem declarar o campo `tenant_id` para defense-in-depth
(SPEC-04 §3). `row_version` é gerenciado por trigger no banco; a entidade deve expô-lo para
leitura (backing do ETag/If-Match, SPEC-04 §6).
