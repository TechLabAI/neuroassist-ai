## Contexto
`PacienteVersionBumper` é o componente responsável por incrementar atomicamente o `catalogo_versao`
na tabela `paciente` toda vez que um Comando do paciente muda de estado (publish/recalibrate/retire).
O `catalogoVersao` é o ETag do endpoint `GET .../catalogo-ativo` — GEST usa `If-None-Match` para
detectar quando deve re-snapshot. Deve ser executado **na mesma transação** que a transição de estado
(SPEC-02 §6).
