# GWY-006 -- Implement TenantContextPropagationFilter (strip inbound, set from principal)

**Status:** INTACT -- gerado 2026-07-27
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/5 itens

## Contexto
Anti-spoofing (INV-2): headers internos `X-Empresa-Id`/`X-Principal-*` recebidos do cliente devem ser removidos antes do gateway definir os seus proprios a partir do `GatewayPrincipal` autenticado.

**Spec de referencia:** SPEC-02, SPEC-06

## Escopo
- [ ] implementar `backend/services/neuroassist-ai-api-gateway/src/main/java/com/neuroassist/gateway/filter/TenantContextPropagationFilter.java`
- [ ] remover `X-Empresa-Id`, `X-Principal-Kind`, `X-Principal-Id` de toda requisicao inbound antes de definir os proprios

## Resultado esperado
Um `TenantContextPropagationFilter` executa strip+set de forma atomica logo apos a autenticacao, garantindo que `X-Empresa-Id` nunca venha do cliente.

## Criterios de aceite
- [ ] requisicao com `X-Empresa-Id` forjado tem o header removido e substituido pelo valor derivado do principal autenticado
- [ ] `X-Principal-Kind` e `X-Principal-Id` sao definidos exclusivamente a partir do `GatewayPrincipal`
- [ ] rota `public` sem `GatewayPrincipal` segue sem esses headers definidos

## Dependencias
GWY-009, GWY-010 (precedem -- authentication resolve o principal antes desta propagacao).
