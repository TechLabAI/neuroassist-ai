# PAC-013 -- Implementar ComandoAuthoringService.editDraft com guard estado=drafted e campos identidade congelados

**Status:** INTACT -- gerado 2026-07-28
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/3 itens

## Contexto
`ComandoAuthoringService.editDraft` permite editar campos de identidade (`rotulo`, `necessidade`,
`primitivos`, `urgencia`) somente enquanto `estado = drafted` (ADR-006). Campos congelados após
publish: se `estado != drafted`, rejeita com `409 /errors/invalid-lifecycle-transition`. A edição
reaplica os mesmos guards de timing e primitivos distintos do `createDraft`.

## Spec de referencia
- SPEC-02 §5 (identity-edit restriction — §7)
- ADR-006 (versioned retire — identity frozen after publish)
- `contracts/api-contract.md` §4.4
