## Contexto
`EmergencyEligibilityGate` é um componente de aplicação que centraliza a lógica do gate (ADR-005,
SPEC-03). Chamado por `ComandoLifecycleService` no `:publish` e no `:recalibrate` que eleva urgência.
Encapsula: chamada a `GestDetectabilityPort.isSupported`, timeout/CB via Resilience4j, e a assimetria
fail-closed (emergência) vs advisory (rotina). `GateResult` é sealed: PASS | BLOCK | WARN | UNAVAILABLE.

- ADR-005 (fail-closed / advisory asymmetry)
