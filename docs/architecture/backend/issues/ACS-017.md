`/api/v1/acs/caregivers/{id}/links`. O `DELETE` usa semântica soft (retorna `200 OK`
com link `revoked`, não `204`).

## Escopo

- [ ] criar `LinkController` com:
      `POST /api/v1/acs/caregivers/{id}/links` → `LinkService.createLink()` → `201` ou `200` (idempotente)
      `GET /api/v1/acs/caregivers/{id}/links` → `LinkService.listLinks()` → `200`
      `DELETE /api/v1/acs/caregivers/{id}/links/{linkId}` → `LinkService.revokeLink()` → `200` (soft)

- [ ] POST idempotente → `200 OK` (não `201`)
- [ ] DELETE → `200 OK` com `status=revoked` (não `204 No Content`)
