## Contexto

`CaregiverPatientLinkJpaAdapter` opera no schema empresa. Contém a lógica de idempotência (link ativo já
existe → retornar o existente), a verificação de cobertura (contagem de active links + coordenadores para
o `pacienteId` antes de revogar), e a revocação soft (set `status = revoked`, `revogado_em = now()`).
