## Contexto
`PacienteService` é o application service que orquestra a criação e atualização de `Paciente`.
Para cada write, resolve referências externas (EDGE para `dispositivoEdgeId`, ACS para cada
`cuidadorResponsavelId`) antes de persistir — cross-service refs não são FK no banco (SPEC-04 §3).
Se EDGE/ACS estiver indisponível, rejeita o write com `503` (SPEC-10 §5.3, §6.3).
