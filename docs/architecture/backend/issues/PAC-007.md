## Contexto
Adapter JPA que implementa `PacienteRepositoryPort`. Toda query é tenant-scoped (aplica
`tenant_id = :tenantId` em todas as queries, defense-in-depth além do schema routing). O campo
`rowVersion` via `@Version` é o mecanismo de concorrência otimista — JPA lança
`OptimisticLockingFailureException` se o version stale, o adapter converte para a exceção de domínio.
