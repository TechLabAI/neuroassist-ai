## Contexto
Configurar o `pac-service` como OAuth2 resource server (JWT bearer). Cada endpoint tem um scope
obrigatório definido em SPEC-01 §7. Além da validação de scope, o JWT deve conter um claim
`empresaId` (ou equivalente) que deve casar com o header `X-Empresa-Id` — se não casar, retorna
`403 /errors/tenant-mismatch` sem vazar se a empresa existe (SPEC-01 §1.1).

## Spec de referencia
- SPEC-06 (security — OAuth2 resource server, scopes, tenant claim)
- SPEC-01 §1.2 (auth scopes), §1.1 (tenant-mismatch EARS)
