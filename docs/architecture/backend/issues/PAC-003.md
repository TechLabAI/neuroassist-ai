## Contexto
Definir as interfaces de port (hexagonal) que isolam a camada `application` da infraestrutura.
Cada port é uma interface Java sem dependências de framework — o adapter (infrastructure) implementa,
o service (application) depende apenas da interface. Derivado de SPEC-10 §4–§7 e SPEC-02 §9.
