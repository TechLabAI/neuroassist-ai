## Contexto
Adapter JPA que implementa `ComandoRepositoryPort`. O caso crítico é a detecção de colisão de
mapeamento ativo (`ux_comando_active_mapping` no banco): quando um `INSERT` viola o índice parcial,
o adapter deve capturar `DataIntegrityViolationException` e converter para `DuplicateActiveMappingException`
→ `422`. O filtro por `estado` é necessário para as listagens (excluir `retired` por padrão).
