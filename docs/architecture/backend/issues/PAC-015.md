## Contexto
`ComandoLifecycleService.publish` é a transição mais crítica: `validated → published`. Executa o
**emergency gate** (ADR-005) para Comandos com `urgencia = emergencia` — fail-closed: qualquer
falha ou timeout em GEST bloqueia o publish com `503`. Para `rotina`, o gate é advisory (warnings).
Após publicação: bump `catalogoVersao` do paciente (PAC-019) e registro síncrono de `ComandoPublicado`
no HIST (INT-PAC-004).
