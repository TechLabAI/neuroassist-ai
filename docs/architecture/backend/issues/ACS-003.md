**Maturidade:** 100 -- Maduro
**Done/Total:** 0/4 itens

## Contexto

ACS depende de quatro outbound ports derivados de `contracts/event-contracts.md §2` e do modelo
hexagonal (RULE-01..08). As ports são interfaces puras em `application/port/` — sem imports
Spring, JPA ou HTTP. Os adapters concretos (REST Feign, JPA) vivem em `infrastructure/`.

Portos críticos (fail-closed): `MigProvisioningPort` (timeout 5s) e `PacPatientResolvePort`
(timeout 2s). Port best-effort: `HistAuditPort` (nunca bloqueia a transação principal).

- SPEC-10 §3.3 (HistAuditPort)
- SPEC-03 §6 (SigningKeyPort — key lookup para assinatura JWT)

## Escopo

- [ ] criar `MigProvisioningPort` com métodos:
      `requestTenantSchema(tenantId: UUID, schemaName: String): MigSchemaResponse`,
      `getTenantSchemaStatus(tenantId: UUID): MigSchemaStatusResponse`
- [ ] criar `PacPatientResolvePort` com método:
      `resolvePatient(pacienteId: UUID, tenantId: UUID): PatientResolveResponse`
      (retorna `Optional<PatientResolveResponse>`; ausência = 404)
- [ ] criar `HistAuditPort` com método:
      `recordFact(fact: AuditFact): void`
      onde `AuditFact` é um value object com campos `fact`, `empresaId`, `actorId`,
      `correlationId`, `occurredAt`, `payload: Map<String, Object>`
- [ ] criar `SigningKeyPort` com métodos:
      `getActiveSigningKey(): SigningKey`,
      `getPublicKeys(): List<PublicKeyMaterial>` (active + recently retired)
- [ ] garantir que nenhuma interface importa classe de infraestrutura (Spring, Feign, JPA)

## Resultado esperado

Quatro interfaces em `application/port/` que invertem as dependências e permitem substituição
de adapters em testes sem Spring context.

## Critérios de aceite

- [ ] Nenhuma port interface possui `import org.springframework.*`, `import javax.persistence.*`
      ou qualquer classe Feign/HTTP
- [ ] `HistAuditPort.recordFact` retorna `void` (fire-and-forget na assinatura; resiliência no adapter)
- [ ] `PatientResolveResponse` tem campo `tenantId` para validação same-tenant (SPEC-10 §2.2)
- [ ] `getPublicKeys()` retorna lista (suporte a múltiplas chaves na rotação — SPEC-03 §6)
