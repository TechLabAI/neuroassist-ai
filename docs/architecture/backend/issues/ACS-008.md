## Contexto

ACS não roda Flyway embarcado — contribui scripts ao serviço centralizado MIG (`neuroassist-ai-migrations`).
Dois bands: `V0200..V0249` (schema global `neuroassist_global`) e `V0250..V0299` (schema por empresa
`t_<tenantId>`). Os DDLs canônicos são os blocos `sql` em `contracts/data-model.md`. Os scripts
devem ser idempotentes (nenhuma migration editada após aplicada) e preservar a ordem
`extensions → tabelas → índices → comentários` em cada bloco (SPEC-04 §5).

## Spec de referência

- SPEC-04 §5 (migration band allocation), §6 (EARS invariants data model)
- `contracts/data-model.md §2` (DDL canônico das 4 tabelas)
