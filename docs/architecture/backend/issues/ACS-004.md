# ACS-004 -- Criar entidades JPA para ambos os schemas (global: Tenant, SigningKey; empresa: Cuidador, CaregiverPatientLink)

**Maturidade:** 0 -- Inicial

## Contexto

ACS abrange dois schemas PostgreSQL: `neuroassist_global` (Tenant, SigningKey) e `t_<tenantId>`
(Cuidador, CaregiverPatientLink). As entidades JPA são somente mapeamentos — toda a lógica
de negócio permanece nos domain aggregates. Colunas de `credential_hash` nunca expõem
o valor em `toString()` ou serialização. `tenant_id` em `Cuidador` e `caregiver_patient_link` é
uma FK lógica (sem `@ManyToOne` cross-schema — PS.003); `paciente_id` em `CaregiverPatientLink`
é referência puramente lógica a um paciente PAC.
