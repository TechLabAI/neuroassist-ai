# ACS-022 -- Implementar Actuator health indicators + métricas Micrometer (acs.auth.attempts, etc.)

**Status:** DONE -- validado 2026-08-19 (Modo 4 FULL-VALIDACAO)
**Maturidade:** 100 -- Maduro
**Done/Total:** 0/4 itens

## Contexto

ACS é um serviço safety-critical: sua health afeta a capacidade de todos os outros serviços
de autenticar e rotear alarmes. O health endpoint deve reportar `db`, `migPort` e `jwkSet`.
Métricas custom cobrem tentativas de login, saga de provisionamento, vínculos e coverage guard.

## Spec de referência

- SPEC-07 §3 (EARS: health indicators, metrics list)

## Escopo

- [ ] criar `MigPortHealthIndicator implements HealthIndicator`:
      faz GET no health do MIG via `MigProvisioningPort`; `DOWN` se unreachable
- [ ] criar `JwkSetHealthIndicator implements HealthIndicator`:
      verifica se há pelo menos uma `signing_key` com `status = 'active'` no banco; `DOWN` se ausente
- [ ] registrar ambos via `@Component`; Spring Boot auto-detecta e inclui em `/actuator/health`
- [ ] registrar métricas Micrometer:
      `Counter` → `acs.auth.attempts` (tags: `outcome=success|failure`)
      `Timer` → `acs.tenant.provisioning.duration`
      `Counter` → `acs.link.created`
      `Counter` → `acs.link.revoked`
      `Counter` → `acs.coverage.guard.triggered`
- [ ] injetar `MeterRegistry` nos services relevantes (AutenticacaoService, TenantProvisioningService, LinkService)

## Critérios de aceite

- [ ] `GET /actuator/health` retorna `db`, `migPort`, `jwkSet` como sub-indicators
- [ ] `jwkSet: DOWN` quando nenhuma `signing_key` ativa existe
- [ ] `acs_auth_attempts_total{outcome="failure"}` incrementado em cada login falhado
- [ ] `GET /actuator/metrics/acs.link.created` retorna o counter

## Dependências

- ACS-009 (TenantJpaAdapter — jwkSet check)
