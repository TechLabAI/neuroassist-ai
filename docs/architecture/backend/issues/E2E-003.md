# E2E-003 — Directory: PAC/EVNT/HIST → ACS + fail-closed behaviors

**Módulo:** E2E Cross-Service  
**Fase:** F3 — Directory ACS → Downstream  
**Prioridade:** P1 (bloqueante)  
**Status:** OPEN  
**Criado em:** 2026-08-20  
**Plano:** [plan-e2e-integration.md](../plans/plan-e2e-integration.md)

---

## Objetivo

Validar que PAC, EVNT e HIST consultam corretamente o Directory do ACS (`/api/v1/acs/directory/**`) para resolução de patient-scope e roteamento de cuidadores — e que os comportamentos fail-closed estão implementados (HIST jamais amplia escopo em caso de indisponibilidade do ACS).

## Contexto

- **PAC** usa `AcsDirectoryPort` para resolver o patient-scope do cuidador antes de filtrar dados
- **EVNT** usa `CaregiverRoutingClient` para descobrir cuidadores responsáveis por um paciente
- **HIST** usa `ActorDirectoryPort` (fail-closed) apenas em leituras com escopo de cuidador (`hist:read`)
- Coordenadores/DPOs com `hist:read:all` NÃO devem chamar ACS

## Cenários de Validação

| ID | Cenário | Fluxo | Critério |
|---|---|---|---|
| DIR-01 | PAC resolve patient-scope de cuidador | `AcsDirectoryPort.getPatientScope(caregiverId)` | lista de `patientId` do tenant retornada |
| DIR-02 | EVNT roteia notificação via directory | `CaregiverRoutingClient` → ACS directory | cuidadores responsáveis retornados corretamente |
| DIR-03 | HIST fail-closed se ACS indisponível | parar ACS → `GET /api/v1/hist/history` como cuidador | `503` com `type: /errors/scope-unavailable` |
| DIR-04 | HIST serve `hist:read:all` sem chamar ACS | token de coordenador → HIST read | `200` — log não deve mostrar chamada ao ACS |
| DIR-05 | Circuit breaker HIST→ACS abre após falhas | simular timeout ACS 5+ vezes → HIST read | CB OPEN; `503` imediato sem esperar timeout |

## Pré-condições

- E2E-001 (stack UP) e E2E-002 (auth OK)
- Cuidador criado e vinculado a pelo menos um paciente (setup de dados)

## Checklist

- [ ] DIR-01: PAC retorna scope correto (apenas pacientes do tenant do cuidador)
- [ ] DIR-02: EVNT descobre cuidadores responsáveis pelo paciente
- [ ] DIR-03: HIST retorna `503` (não dados não-filtrados) quando ACS está down
- [ ] DIR-04: coordenador recebe dados completos sem ACS ser chamado
- [ ] DIR-05: CB abre após threshold e falha rápida sem esperar timeout
