# ACS-018 -- Implementar DirectoryService + DirectoryController (4 endpoints read-only)

**Status:** DONE -- validado 2026-08-19 (Modo 4 FULL-VALIDACAO)
**Maturidade:** 100 -- Maduro
**Done/Total:** 0/5 itens

## Contexto

A superfície de diretório (`/api/v1/acs/directory`) é o ponto de leitura de todos os outros
serviços: EVNT (routing targets), DASH/PAC/HIST (data-scope), todos (tenant validity).
É crítica para alarmes: uma falha no `GET /directory/patients/{pid}/caregivers` pode silenciar
um alarme de emergência. `Cache-Control: max-age=60` em todos os endpoints.

## Spec de referência

- SPEC-01 §6 (directory endpoints)
- `contracts/api-contract.md §6` (4 endpoints completos)
- SPEC-10 §3.2 (directory SLA: 100ms p99, Cache-Control)

## Escopo

- [ ] criar `DirectoryService` em `application/service/` com:
      `resolveTenantValidity(tenantId): TenantValidityView`
      `resolveRoutingTargets(pacienteId, tenantId): RoutingTargetsView` (active links + all coordenadores)
      `resolveCaregiverRole(cuidadorId): CaregiverRoleView`
      `resolvePatientScope(cuidadorId): PatientScopeView` (assigned para cuidadora, tenant para coordenador)
- [ ] criar `DirectoryController` com 4 `GET` endpoints; `@PreAuthorize("hasAuthority('acs.directory.read')")`
- [ ] retornar `responsibleCaregivers: []` (não 404) quando nenhum cuidador ativo cobre um paciente
- [ ] adicionar `Cache-Control: max-age=60` em todos os responses de diretório (via `HttpServletResponse`)
- [ ] `resolveRoutingTargets`: incluir todos os `coordenador_clinica` ativos do tenant mesmo sem link explícito (coordinator-override ADR-006)

## Critérios de aceite

- [ ] Nenhum cuidador ativo para um paciente → `200 OK` com `responsibleCaregivers: []`
- [ ] Coordenador incluído em routing mesmo sem link explícito ao paciente
- [ ] `scope=tenant` retornado para coordenador em `patient-scope`
- [ ] `Cache-Control: max-age=60` presente nos headers de response
- [ ] Response em < 100ms p99 (DB read local, sem chamada remota)
