# ACS-023 -- Configurar ArchUnit rules (hexagonal boundaries, LGPD, no credential leakage)

**Status:** DONE -- validado 2026-08-19 (Modo 4 FULL-VALIDACAO)
**Maturidade:** 100 -- Maduro
**Done/Total:** 0/3 itens

## Contexto

ArchUnit valida em tempo de build que as regras arquiteturais são respeitadas: hexagonal
boundaries (domain/application não dependem de infrastructure/api), ausência de credenciais
em tipos de response, e ausência de dependências cruzadas proibidas.

## Spec de referência

- SPEC-06 §4 (LGPD: credential_hash nunca em response DTO)
- `docs/architecture/backend/standards/hexagonal-patterns.md` (RULE-01..06)

## Escopo

- [ ] criar `HexagonalArchitectureTest` com ArchUnit (seguindo padrão dos outros serviços):
      RULE-01: `domain` não depende de `infrastructure` nem de `api`
      RULE-02: `application` não depende de `infrastructure` nem de `api`
      RULE-03: `infrastructure` não depende de `api`
      RULE-04: apenas `infrastructure` implementa ports declarados em `application.port`
      RULE-05: classes com `@RestController` residem apenas em `api.controller`
      RULE-06: classes com `@Entity` residem apenas em `infrastructure.persistence`
- [ ] criar regra adicional: nenhum DTO em `api/dto/` pode ter campo nomeado `credentialHash`, `senha`, `password`, `privateKey`
- [ ] garantir que `./gradlew :acs-service:test` executa ArchUnit como parte do build padrão

## Critérios de aceite

- [ ] Violação de RULE-01 (domain importando infrastructure) → build falha com mensagem clara
- [ ] DTO com campo `credentialHash` → ArchUnit falha
- [ ] Todas as 6 regras RULE-01..06 PASS no build limpo
