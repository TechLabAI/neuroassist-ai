# E2E-026 — `POST /gest-service/detection-contract` é guardado por uma authority de leitura

**Módulo:** GEST + ACS
**Fase:** F2 — Auth Backbone
**Prioridade:** P3
**Status:** OPEN
**Criado em:** 2026-08-23
**Plano:** [plan-e2e-integration.md](../plans/plan-e2e-integration.md) §11.2

---

## Contexto

`POST /gest-service/detection-contract` — uma escrita — está protegido por
`gest.detection-contract.read`.

Funciona hoje por acidente: o ACS emite `.read` para ambos os papéis, então a chamada passa. Mas o
modelo está errado, e o erro é do tipo que só aparece quando alguém restringe corretamente a
leitura e descobre que restringiu a escrita junto — ou o contrário, dá `.read` a um papel de
consulta e concede escrita sem perceber.

## Escopo

- `gest.detection-contract.write` (ou `.criar`, seguindo a convenção do catálogo) criada e emitida
  a quem hoje escreve
- `@PreAuthorize` do endpoint trocado
- Varredura pelos 7 serviços procurando o mesmo padrão: verbo de escrita guardado por authority de
  leitura

## Checklist

- [ ] Nova authority no `RoleAuthorityPolicy` do ACS + catálogo de permissões
- [ ] `@PreAuthorize` do endpoint atualizado
- [ ] Teste negativo: token só com `.read` recebe 403 no POST
- [ ] Varredura cross-service por outros casos
- [ ] Regra ArchUnit, se o padrão for detectável estaticamente

## Dependência

E2E-002, E2E-023 (mesma família — catálogo de authority)
