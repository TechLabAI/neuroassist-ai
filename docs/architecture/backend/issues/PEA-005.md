# PEA-005 -- GestureClassifier: inferência ONNX + CommandMatcher (timing + debounce)

**Status:** PENDENTE | **Prioridade:** P2 | **Estimativa:** M

## Spec de referência

- `01-architectural-vision.md §3.3` (GestureClassifier) e `§3.4` (CommandMatcher)

## Escopo

### GestureClassifier (`classifier.py`)

- [ ] carregar modelo ONNX via `onnxruntime.InferenceSession` (model path de `capture.model_path`)
- [ ] input: landmarks normalizados de `LandmarkSet` → flat numpy array
- [ ] output: `ClassificationResult(primitive_code: str, confidence: float)`
- [ ] confidence threshold aplicado por `CommandMatcher` (não pelo classifier)
- [ ] classificação a cada frame que tem `LandmarkSet` não vazio

### CommandMatcher (`matcher.py`)

- [ ] estado: dicionário `{primitive_code: GestureWindow}` com:
  - `start_time`, `last_seen`, `duration_ms` (acumulado enquanto gestos consecutivos)
- [ ] lógica de match (por `Comando` no vocabulário):
  1. `primitivoPrincipal` detectado com confidence ≥ threshold(sensibilidade)
  2. duração dentro de [`tempoMinGestoMs` .. `tempoMaxGestoMs`]
  3. se `primitivoSecundario`: detectado dentro de 500ms após o fim da janela principal
- [ ] debounce: após match, cooldown de `tempoMaxGestoMs + 200ms` para o mesmo `comandoId`
- [ ] on match: chamar `EventPublisher.enqueue(GestoDetectado)`
- [ ] thresholds de confiança: `alta=0.90`, `media=0.75`, `baixa=0.60`

## Critérios de aceite

- [ ] gesto simples com 1s de hold → evento emitido (unit test com mocked classifier)
- [ ] gesto composto (2 primitivos, sequência correta) → evento emitido
- [ ] gesto composto (sequência errada) → sem evento
- [ ] debounce: segundo match dentro do cooldown → sem evento adicional
- [ ] confidence abaixo do threshold → sem evento
