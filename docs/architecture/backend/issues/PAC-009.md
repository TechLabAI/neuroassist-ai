## Contexto
Implementar o mecanismo de schema-per-tenant (multi-empresa, SPEC-04 §3). `TenantContextHolder`
armazena o `empresaId` do request atual em `ThreadLocal`. `TenantSchemaResolver` executa
`SET search_path TO t_<empresaId>` no início de cada conexão do pool, garantindo que todas as
queries JPA sejam roteadas para o schema correto sem modificar cada query individualmente.
