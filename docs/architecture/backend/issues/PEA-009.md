# PEA-009 -- Integração e2e + empacotamento Docker + deployment guide

**Status:** PENDENTE | **Prioridade:** P4 | **Estimativa:** M

## Escopo

### Integration tests (`tests/integration/`)

- [ ] teste de fluxo completo com mocks HTTP (`respx` para httpx):
  - enrollment → vocabulário → gesto detectado → evento entregue
- [ ] teste de resiliência: EVNT down → outbox → retry → entrega quando EVNT volta
- [ ] teste LGPD: nenhum arquivo de vídeo/imagem criado durante qualquer test run

### Docker packaging

- [ ] Dockerfile multi-stage:
  - Stage 1 (`builder`): instalar deps, compilar wheels nativas (OpenCV headless, ONNX)
  - Stage 2 (`runtime`): `python:3.11-slim` + `libgl1-mesa-glx` (OpenCV display) + wheels copiadas
- [ ] imagem final < 600 MB
- [ ] `docker run --device /dev/video0 ...` funcional (bind do dispositivo de câmera)
- [ ] `Makefile docker-build` + `docker-push`

### Deployment guide (`docs/deploy.md`)

- [ ] Raspberry Pi 4: dependências do SO, `pip install`, `systemd` unit file (`neuroassist-edge.service`)
- [ ] Windows 10/11: Python 3.11 installer, `pip install`, task scheduler ou NSSM para rodar como serviço
- [ ] enrollment walkthrough passo a passo
- [ ] troubleshooting: câmera não detectada, ACS unreachable, GEST unreachable

## Critérios de aceite

- [ ] integration test de fluxo completo passa sem câmera física (mock frame generator)
- [ ] `docker build .` produz imagem < 600 MB
- [ ] `systemd` unit file valida com `systemd-analyze verify`
- [ ] nenhum arquivo de vídeo criado durante qualquer test (verificado via `find . -name "*.mp4" -o -name "*.jpg"`)
