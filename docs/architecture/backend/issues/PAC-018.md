## Contexto
`ComandoLifecycleService.recalibrate` executa ajuste de tuning in-place (SPEC-02 §5.4). Só permite
editar `sensibilidade`, `tempoMinGestoMs`, `tempoMaxGestoMs`, `urgencia` — campos de identidade
(`rotulo`, `necessidade`, primitivos) são congelados (ADR-006). Se a recalibração eleva `urgencia`
para `emergencia` (ou o comando já é emergência), re-executa o emergency gate. Incrementa
`calibracaoVersao` por exatamente 1 e bumpa `catalogoVersao`.
