# REG-009 -- Docker Compose local: neuroassist-ai-service-registry + healthcheck

**Status:** INTACT -- gerado 2026-07-27
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/7 itens

## Contexto
O registry e o primeiro servico a subir no `docker-compose.yml` local -- todos os demais servicos que declaram `eureka.client.serviceUrl.defaultZone` precisam que ele esteja healthy antes de iniciar. O healthcheck via readiness endpoint garante o ordering correto no compose. Sem esse servico, o fluxo de desenvolvimento local de qualquer outro modulo (GEST, EVNT, PAC, ACS, HIST, DASH, EDGE, GWY) fica bloqueado.
