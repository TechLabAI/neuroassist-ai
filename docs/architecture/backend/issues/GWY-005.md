**Status:** INTACT -- gerado 2026-07-27

## Contexto
A ordem de filtros e normativa e nao-reordenavel sem revisao (`CORS -> CorrelationId -> Authentication -> TenantContextPropagation -> RateLimiter -> Route -> ProblemDetailError`); cada estagio precisa de `getOrder()` explicito para nao depender de ordem implicita do Spring.

**Spec de referencia:** SPEC-02

## Escopo

## Resultado esperado
