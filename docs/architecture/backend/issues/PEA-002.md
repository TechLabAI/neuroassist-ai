# PEA-002 -- AuthClient: OAuth2 client_credentials contra ACS + token cache

**Status:** PENDENTE | **Prioridade:** P1 | **Estimativa:** S

## Spec de referência

- `contracts/api-consumed.md §1` (ACS token endpoint)

## Escopo

- [ ] implementar `AuthClient` em `auth.py`
  - `POST /oauth2/token` com `grant_type=client_credentials`, `scope=edge:publish`
  - cache em memória (JWT dict); refresh 60s antes da expiração
  - `client_secret` lido do OS keychain via `keyring` (`NEUROASSIST_DEVICE_SECRET` como fallback env)
- [ ] tratamento de `401 invalid_client` → log CRITICAL + exit (não retry automático)
- [ ] tratamento de ACS unreachable → usar cached token; após expiração → lançar `AuthUnavailableError`
- [ ] expor `async def get_token() -> str` (reaproveita cache se válido)

## Critérios de aceite

- [ ] token cacheado; segundo `get_token()` sem chamada HTTP (validado em unit test com mock)
- [ ] refresh chamado automaticamente quando `expires_in - 60s` transcorrido
- [ ] `AuthUnavailableError` lançado após expiração sem ACS disponível
