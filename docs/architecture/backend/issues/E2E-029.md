# E2E-029 — Um tenant novo nasce vazio e ninguém consegue entrar nele (C-48)

**Módulo:** E2E Cross-Service (ACS)
**Fase:** F9 — Flow-01 (onboarding)
**Prioridade:** P1
**Status:** OPEN
**Criado em:** 2026-08-23 — descoberto ao validar E2E-016 contra o stack real
**Plano:** [plan-e2e-integration.md](../plans/plan-e2e-integration.md) §11.2

## Contexto

Com E2E-016 no ar, `POST /api/v1/acs/tenants` cria o schema de verdade e devolve o tenant
`ACTIVE`. O passo seguinte não existe: **não há como criar o primeiro cuidador desse tenant.**

```
POST /api/v1/acs/caregivers?tenantId=<tenant-novo>
  → 403 acs.tenant.mismatch
    "Caregiver does not belong to the requested tenant"
    actualTenantId: <tenant de quem chamou>   requestedTenantId: <tenant novo>
```

O 403 está **correto**: um coordenador da clínica A não pode criar pessoas na clínica B, e esse
isolamento é o que impede vazamento entre empresas. O problema é que ele fecha o único caminho
existente, e não há nenhum outro:

- todo token é emitido para um cuidador, e todo cuidador pertence a um tenant;
- o tenant recém-criado não tem cuidador nenhum;
- logo, nenhum token pode agir dentro dele.

O tenant fica com schema perfeito, 30 tabelas migradas, e inalcançável. O seed
(`V0102__acs_dev_seed.sql`) resolve isso para `t_emp_dev` inserindo linhas direto no banco — que
é exatamente por que as seis sessões de E2E nunca esbarraram nisto.

## O que falta decidir

| Opção | Consequência |
|---|---|
| Ator de plataforma (papel acima do tenant) com autoridade para semear o primeiro cuidador | Cria um papel que atravessa empresas — precisa de trilha de auditoria à altura |
| `POST /tenants` aceita o primeiro coordenador no mesmo payload, criado atomicamente | Onboarding vira uma operação só; o tenant nunca existe sem ninguém dentro |
| Endpoint de bootstrap de uso único por tenant, com token de convite | Mais partes móveis; o convite vira credencial a proteger |

A segunda é a mais simples de defender: um tenant sem nenhum cuidador não é um estado
que o negócio queira, então não deveria ser representável.
