## Contexto
`ComandoController` expõe os 8 endpoints do recurso `Comando` (SPEC-01 §4) e os 4 endpoints de
lifecycle (`:validate`, `:publish`, `:recalibrate`, `:retire`). É nested sob `/pacientes/{pid}`.
Cada endpoint de lifecycle retorna `200` com o `ComandoResponse` atualizado (incluindo `warnings[]`
no caso de advisory gate). Retorna `ETag` com `calibracaoVersao` nas respostas de Comando.
