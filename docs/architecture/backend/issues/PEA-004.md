# PEA-004 -- CaptureModule: loop OpenCV + LandmarkExtractor MediaPipe

**Status:** PENDENTE | **Prioridade:** P2 | **Estimativa:** M

## Spec de referência

- `01-architectural-vision.md §3.1` (CaptureModule) e `§3.2` (LandmarkExtractor)

## Escopo

- [ ] implementar `CaptureModule` em `capture.py`
  - thread dedicada (`threading.Thread`) com loop `cv2.VideoCapture(device_index)`
  - FPS configurável (`capture.fps`, default 15)
  - resolução configurável (`capture.resolution`, default 640×480)
  - frames publicados em `asyncio.Queue(maxsize=5)` (overflow → drop oldest, log DEBUG)
  - `start() / stop()` com cleanup `VideoCapture.release()`
- [ ] implementar `LandmarkExtractor` em `landmarks.py`
  - consumidor da frame queue
  - `mediapipe.solutions.face_mesh.FaceMesh(static_image_mode=False, max_num_faces=1)`
  - output: `LandmarkSet(face_landmarks: list[NormalizedLandmark], timestamp_ms: int)`
  - frames sem face detectada → `LandmarkSet` vazio (não publica, log DEBUG)
- [ ] LGPD guard: nenhum frame é gravado em disco ou logado; apenas coordenadas de landmarks processadas

## Critérios de aceite

- [ ] 15fps sustentado em Raspberry Pi 4 (medido em integration test com webcam mock)
- [ ] frame sem face → nenhum output downstream
- [ ] `stop()` libera câmera sem hang
- [ ] nenhum arquivo de vídeo/imagem criado em nenhum código path
