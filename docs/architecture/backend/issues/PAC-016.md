## Contexto
`ComandoLifecycleService.retire` executa a transição `any → retired` (SPEC-02 §5.5). É terminal e
history-preserving: o registro **nunca** é deletado do banco (ADR-006 — preservação histórica para
HIST/EVNT interpretarem eventos passados). Bumpa `catalogoVersao` (GEST detecta que re-snapshot é due)
e registra `ComandoAposentado` no HIST.
