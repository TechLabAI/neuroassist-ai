## Objetivo

Criar uma suíte de testes E2E automatizada que execute os fluxos dos issues E2E-001 a E2E-012 de forma repetível em CI, sem intervenção manual. A suíte deve poder rodar contra o stack local (docker-compose) e futuramente contra um ambiente de staging.

## Opções de Implementação

### Opção A — REST Assured (Java, integrado ao Gradle)

- Módulo Gradle: `backend/services/e2e-tests/` (novo módulo, não um microserviço)
- Depende de todos os serviços rodando (via docker-compose ou Testcontainers)
- Usa Spring Boot Test + RestAssured para chamadas REST
- Execução: `./gradlew :services:e2e-tests:test`

### Opção B — Newman / Postman Collection

- Arquivo: `docs/e2e/neuroassist-e2e.postman_collection.json`
- Environments: `local.postman_environment.json`, `staging.postman_environment.json`
- Execução: `newman run neuroassist-e2e.postman_collection.json -e local.postman_environment.json`
- Mais fácil de criar manualmente; menos integrado ao Gradle

### Recomendação

**Opção A** para integração com CI/CD Gradle existente. **Opção B** para prototipagem rápida e validação manual durante o desenvolvimento.
