**Status:** INTACT -- gerado 2026-07-28

## Contexto
Implementar o `PacienteController` Spring MVC que expõe os 4 endpoints de `Paciente` (SPEC-01 §4).
O controller cuida de: extrair `X-Empresa-Id`/`X-Correlation-Id` de headers, aplicar scopes OAuth2
(`@PreAuthorize`), montar `Location` no 201, e retornar `ETag` com o `rowVersion`. A lógica de
negócio fica em `PacienteService` (PAC-006).
