## Contexto
`ComandoLifecycleService.validate` executa a transição `drafted → validated` (SPEC-02 §5.2).
O guard principal é resolver cada `primitivo_*_id` referenciado contra GEST via
`GestDetectabilityPort.resolveTipoGesto` — a existência do gesto no sistema GEST é verificada
aqui. A detecção de suporte (`supported`) é verificada apenas no `:publish` (emergency gate, PAC-017).
Se GEST retorna 404 para um primitivo, rejeita com `422`.
