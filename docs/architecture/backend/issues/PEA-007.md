# PEA-007 -- HeartbeatReporter + enrollment flow + ConfigLoader

**Status:** PENDENTE | **Prioridade:** P3 | **Estimativa:** S

## Spec de referência

- `contracts/api-consumed.md §4` (EDGE heartbeat + enrollment)
- `01-architectural-vision.md §3.7` (HeartbeatReporter) e `§3.9` (ConfigLoader)

## Escopo

### ConfigLoader (`config.py`)

- [ ] leitura em cascata: env vars (`NEUROASSIST_*`) → `~/.neuroassist/config.toml` → `./config.toml`
- [ ] campos obrigatórios: `backend.url`, `device.id`, `device.patient_id`, `device.tenant_id`
- [ ] startup falha com mensagem clara se algum campo obrigatório ausente
- [ ] `config.toml.example` atualizado com todos os campos e comentários

### Enrollment command (`python -m neuroassist_edge enroll`)

- [ ] argumento `--enrollment-token <token>` (ou `NEUROASSIST_ENROLLMENT_TOKEN` env)
- [ ] `POST /api/v1/edge/devices/enroll` com o token one-time
- [ ] resposta: persiste `deviceId`, `patientId`, `tenantId` em `config.toml` e `clientSecret` no OS keychain
- [ ] erro `401` ou `410` → mensagem clara: "token expirado ou inválido; solicite um novo no painel"

### HeartbeatReporter (`heartbeat.py`)

- [ ] background asyncio task, intervalo 30s
- [ ] `POST /api/v1/edge/devices/{deviceId}/heartbeat` (best-effort: exception capturada e logada, sem crash)
- [ ] payload: `status`, `fps` (media movel 10s), `outboxDepth`, `agentVersion`

## Critérios de aceite

- [ ] config ausente → mensagem de erro clara na inicialização
- [ ] enrollment bem-sucedido → `config.toml` atualizado e `keyring` persistido
- [ ] heartbeat falha → log WARN, agente continua operando
